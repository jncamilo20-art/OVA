## 📁 Estructura del Proyecto

En este directorio se encuentran organizados todos los archivos de código y recursos multimedia del OVA:

| Archivo | Descripción |
| :--- | :--- |
| **`index.html`** | Estructura principal del OVA (unidades temáticas, simulador, laboratorio y certificado). |
| **`style.css`** | Hoja de estilos CSS completa (diseño cyber-dark, animaciones, componentes y responsive). |
| **`script.js`** | Código JavaScript con la lógica de gamificación, XP, simulador termodinámico, clasificación de eventos y certificado. |
| **`FONDO.png`** | Fotografía oficial del campus de la Universidad Simón Bolívar utilizada como fondo institucional. |
| **`logo.png`** | Escudo institucional oficial de la Universidad Simón Bolívar. |
| **`README.md`** | Documentación técnica y académica del OVA. |

---

## 🚀 Cómo Ejecutar

1. Abre el archivo **`index.html`** en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox o Safari).
2. No requiere servidor externo ni dependencias adicionales (100% Vanilla HTML5, CSS3 y JavaScript).
3. Para refrescar cambios tras editar `style.css` o `script.js`, presiona **`Ctrl + F5`** en el navegador para recargar la caché.
